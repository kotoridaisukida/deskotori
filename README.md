# 抢镜鸟

南小鸟会随机出现在桌面的四个角。左上、右上、左下、右下各转一个方向，图里的直角贴住屏幕的直角，两条直边顺着屏幕边，中间不留缝。隔多久换一次，你自己定。

头像按原图做了高清放大，大约 2000 像素，边缘是透明的，贴在桌面上没有黑框。放大之后，把她调到比较大也仍然清楚。

## 运行

Linux 和 macOS：

```bash
chmod +x run.sh
./run.sh
```

Windows 解压后双击 `run.bat`。也可以在项目目录打开终端：

```bat
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

需要一块能显示窗口的桌面。Linux 上如果小鸟变成一块黑底，打开桌面的合成器（窗口特效），透明背景才会生效。

## 怎么用

第一次打开会弹出设置。

- **刷新时间**：1 秒到 5 分钟。可以用滑块、预设，也可以直接输入秒数。改完会重新计时。
- 时间一到，她从现在这个角消失，随机出现在**另一个**角。
- 点设置里的某个角，她会马上过去。
- **形象大小**会立刻生效。她始终贴着屏幕边，不会往外探。
- 点桌面上的小鸟，可以再次打开设置。
- 右键小鸟，或者点托盘图标，可以暂停、立刻换角，或者退出。
- 关掉设置窗口不会退出，她还会留在桌面上。

设置会记在本机（`~/.config/qiangjing-niao/config.json`），下次打开还在。
